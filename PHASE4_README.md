# My Wealth v0.4 — Phase 4

Investment transaction engine.

## Added
- BUY / SELL / SIP / DIVIDEND / FEE / SPLIT / BONUS transaction types
- FIFO cost lots for sell transactions
- Realized P&L calculation
- Investment transaction history
- XIRR calculation for lots/current value
- Automatic dividend entry into income
- Portfolio transaction summary
- Search holdings

## Important
This phase does not claim tax advice or tax filing calculations. It provides transaction/cost-basis mechanics. Tax rules and brokerage-specific treatment should be validated before relying on figures for filing.

Run: npm install && npm run dev
