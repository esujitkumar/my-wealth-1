# My Wealth v0.7 — Phase 7

## Android + Offline-first foundation

- IndexedDB-backed local database for finance records.
- Automatic fallback to the existing localStorage data format.
- PWA install prompt in Settings when supported by the browser.
- Capacitor configuration for future native Android packaging.
- Existing Phase 6 market, analytics, transactions, backups and responsive UI retained.

## Important

The app is still a web/PWA source package. An APK requires the Android/Capacitor build toolchain (Android Studio + SDK). See `ANDROID_SETUP.md`.
